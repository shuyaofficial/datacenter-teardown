datacenter-teardown

データセンターの機器を分解して見る

ネットワーク機器やサーバーの中で何が起きているかを、ブラウザで触れる3Dにしました。放っておくと自動で案内が流れ、どこかを押すと自分で操作できます。数値には出典を付けています。

スイッチ（Catalyst 9300-48P を模した 1U）

フレームは ASIC の中で 256 B の切れ端に分かれ、本体はバッファに置かれたまま、64 B の札だけが検索とキューを回る。CPU に上がるのは自分宛てと制御だけで、2本の 1G が1本に集まると出口のキューは 1.2288 ms で満杯になる。会社のフロアで PC や電話をつなぐ種類で、AI の GPU どうしをつなぐ所には使わない。

GPU ラック（GB200 NVL72 を模した 72 GPU）

GPU 1個の 18 本のリンクは 18 個のスイッチチップに1本ずつ行くので、どの GPU からどの GPU へもスイッチ1段で届く。ラックの外は中の 18 分の1の速さで、集計をスイッチの中でやると送る量は 1.972 GB から 1 GB に減る。120 kW を直流 50 V の母線で運び込み、液で冷やす。
