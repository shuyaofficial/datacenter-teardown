## 0. 冒頭
- 見出し: AI データセンターの1部屋を歩く
- リード: ChatGPT や Claude に1回質問すると、どこかの部屋で GPU が動き、電気を食べ、熱を出す。その部屋の一角を、実物の資料に合わせて作りました。
- ボタン: 「部屋を歩いてみる」（部屋ツアーへ）

## 1. 部屋の全景（still: overview）
- GPU ラックは 8 本で1組。1組で GPU は 576 個、電気は約 1.2 MW。家庭なら 400 軒ほどの量（推: 1軒 3 kW 換算）。
- 列の両側にネットワークのラック、端にストレージと管理のラック。
- 札: 8 本 / 576 GPU / 約 1.2 MW

## 2. GPU ラック（still: nvl72-front）
- 高さ 2.2 m・幅 60 cm のラックに、GPU 72 個が入る。72 個は銅のケーブルで直結され、1つの大きな GPU のように動く。
- 前面に見える黄色い線は光ファイバ。ラックの外の GPU とつなぐ。
- 札: 72 GPU / 約 120 kW / 1.8 TB/s（GPU 1個の NVLink）
- リンク: GPU ラックを分解する（nvl72-live.html、横向きで）

## 3. ネットワークのラック（still: network）
- ラックとラックをつなぐスイッチ。GPU どうしの網と、データを保存する網、機器を管理する網は、線そのものが別。
- 一番上の小さなスイッチは管理用。会社のフロアのスイッチ（Catalyst）に一番近い役目。
- 札: 網は物理的に4つ / ラックの外はラックの中の 18 分の1 の速さ
- リンク: スイッチを分解する（switch-live.html、横向きで）

## 4. 電気の通り道（still: ceiling）
- 天井のバスウェイ（給電レール）から、差し込み口を通って各ラックへ。ラックの中で電源棚が直流 約50 V にして、背面の太い銅の板（バスバー）で各トレイへ配る。
- 停電に備える UPS は部屋の外の電気室。
- 札: ラック1本 60 A × 8 回路 / バスバー 1,400 A

## 5. 液で冷やす（still: hot-aisle と cdu）
- GPU の上の金属の板（コールドプレート）に冷却液が流れ、熱を持ち去る。熱の 87% は液、13% は空気。
- 液は2つの輪。ラックと CDU の間（40 ℃ で行き、54 ℃ で戻る）と、CDU と屋外の冷却器の間（37 ℃ で入り、47 ℃ で出る）。2つの液は混ざらない。
- 空気で残る熱は、ラックの背面側の通路を囲って閉じ込め、空調へ戻す。
- 札: 液 87% / 40 → 54 ℃ / 37 → 47 ℃
- 図: 2つの輪の SVG（すり合わせページの図を流用）

## 6. 部屋の外（still: window）
- 窓の向こうは電気室と、屋外の冷却器。建物全体でこの部屋が何十と並ぶ。
